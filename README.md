# Assembly-Language-for-x86-processors---Kip-Irvine-solutions-for-parts-4-16-

This project contains solutions for the book of Kip Irvine (Parts 4 to 16).

All code was written and tested using VS2015 (thank you Microsoft), MASM32 and MASM16 (thank you Hutch, Iczelion and many many others).

OS: Win10, WinXP (DOS-emulation) and FreeDOS.

For the purpose of simplicity, if project contains several files (e.g. code written in C/C++ and code written in ASM), they all are combined in the same TXT file. 

## Source layout

The original `.txt` snippets are still kept at the repository root.  Buildable
copies live under `solutions/`:

- `solutions/partNN/` - one `.asm` or `.cpp` file per snippet (parts 4-16).
- `solutions/part13/13.7-*` - chapter 13 snippets that combine C++ and MASM;
  each section is split into its own `main.cpp`, `module.asm`, etc.
- `solutions/manifest.json` - mapping from each original `.txt` file to the
  generated source file(s).
- `solutions/README.md` - human-readable version of the same mapping.

The sources are generated by `scripts/convert_snippets.py`.  The converter
also contains the small fixes needed to make the transcribed snippets
assemble (a few uncommented prose lines, truncated `PROTO` lists, missing
`PROC`/`ENDP`, and immediates that do not fit in 16 bits).  Do not edit the
files under `solutions/` by hand; change the converter or the original snippet
and regenerate.

## Building

`third_party/irvine/` contains the Irvine include files needed by the MASM
sources.  [JWasm](https://github.com/Baron-von-Riedesel/JWasm) is a
MASM-compatible assembler that handles both the 16-bit DOS programs and the
32-bit Windows programs in this repository:

```sh
jwasm -nologo -c -Ithird_party/irvine -Fo/tmp/out.obj solutions/part05/5.9.1.asm
```

The GitHub Actions workflow `.github/workflows/asm-build.yml` regenerates the
sources, checks them into sync, validates the tree, assembles every `.asm`
file with JWasm, and syntax-checks the portable C++ files with `g++`.
